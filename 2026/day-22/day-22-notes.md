# Day 22 Notes – Git Basics

1. **Difference between git add and git commit**  
- `git add` stages changes for the next commit.  
- `git commit` actually records the changes in the repository.

2. **Staging area purpose**  
- It allows you to review and group changes before committing.  
- Helps to organize commits logically instead of committing everything at once.

3. **Information shown by git log**  
- Commit hash, author, date, and commit message.  
- Shows chronological history of changes.

4. **.git folder**  
- Stores all Git metadata (commits, branches, config, objects).  
- Deleting it removes version control from the project.

5. **Working directory vs staging area vs repository**  
- **Working directory**: Your files on disk (editable).  
- **Staging area**: Where you prepare changes for commit.  
- **Repository**: Where committed history is stored permanently.
